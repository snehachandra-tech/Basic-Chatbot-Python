# Basic Chatbot Python 🤖

A simple rule-based chatbot built using Python. This project is created as part of **CodeAlpha Internship – Task 4: Basic Chatbot**.

The chatbot interacts with users through the terminal and provides predefined responses to common messages such as hello, how are you, and bye.

## 📌 Project Overview

This project demonstrates how to create a basic chatbot using Python programming concepts. It uses conditional statements and loops to take user input and generate appropriate responses.

## ✨ Features

* Responds to greetings like "hello".
* Replies to "how are you".
* Displays a goodbye message when the user types "bye".
* Runs continuously until the user exits.
* Handles unknown messages with a default response.
* Beginner-friendly Python implementation.

## 🧠 Key Concepts Used

* `input()` – Takes input from the user.
* `print()` – Displays chatbot responses.
* `if-elif-else` – Checks user messages.
* `while` loop – Keeps the chatbot running.
* `break` – Exits the chatbot.
* `.lower()` – Converts input to lowercase.
